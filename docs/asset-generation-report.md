# 动画素材生成报告

## 产物

- 六个状态，每个状态 16 帧，路径为 `src/assets/pet/<state>/00.png` 至 `15.png`。
- 奇数编号帧由相邻动作关键帧生成，用于提高时间采样密度；偶数编号帧保留原始动作关键帧。
- 所有运行帧为 512×512 RGBA PNG；`walking` 朝右，向左由 CSS 水平镜像。
- 原始 4×2 生成接触表保存在 `artifacts/asset-work/source-sheets/`。
- 相邻关键帧的 4×2 中间帧表保存在 `artifacts/asset-work/midpoint-sheets/`。
- 使用内置图像生成工具生成接触表；使用 `scripts/split_sprite_sheet.py` 切帧、转 RGBA、
  去除纯绿背景，再由 `scripts/build_16_frame_set.py` 交错为 16 帧。脚本只使用 Python
  标准库，便于复现。

## 各状态参考和补全

| 状态 | 实际参考图 | 参考作用 | 补全动作 |
|---|---|---|---|
| `sitting` | 全身、平静 | 全身比例、脸型、毛色、折耳 | 呼吸、眨眼、耳动的循环 |
| `walking` | 全身、平静 | 身份、体型和侧视转换依据 | 朝右完整步态与轻微重心起伏 |
| `sleeping` | 全身、平静 | 毛色、头身比例、折耳 | 蜷卧姿势、呼吸、耳/尾尖轻动 |
| `happy` | 全身、平静、微笑 | 身体、身份、开心张嘴表情 | 前倾、吞咽、笑、满足收回 |
| `petting` | 全身、平静、微笑 | 身体、身份、放松表情 | 低头、眯眼、轻微侧头、恢复 |
| `hissing` | 全身、平静、哈气 | 身体、身份、飞机耳与口腔动作 | 警觉、逐渐张嘴、哈气峰值、收回 |

## 一致性与质量检查

- 六套图保持圆头、橘色短毛、折耳、深色圆眼和一致的头身关系。
- 每张接触表按规则网格切分，最终帧统一画布且没有拉伸输入参考图。
- 透明角已人工查看；主体轮廓可辨，保留轻微绿缘/旧抠图 halo，符合“包浆”方向。
- `hissing` 峰值帧已人工检查，表达为哈气而非普通打哈欠。
- 行走和睡眠是参考图中没有的全新姿势，仍建议在 Windows/macOS 实机播放后复核循环节奏。

## 生成提示词摘要

共同约束：真实低清视频截帧、同一只圆头橘猫、4×2 等分接触表、纯 `#00ff00`
背景、无阴影/文字/道具/额外肢体、固定比例与基线；每个状态仅改变对应的呼吸、步态、
睡眠、吞咽开心、被抚摸或哈气动作。完整提示词的状态差异与所用参考图已体现在上表，
且实际调用与表中记录一致。

## 仍需实机确认

- 半透明毛发边缘在不同桌面壁纸上的绿溢色可接受程度；
- Retina 与 Windows 150%/200% 缩放下的轮廓和包浆强度；
- 16 帧循环在目标平台窗口移动时的视觉连续性。
