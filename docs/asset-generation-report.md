# 动画素材生成报告

## 产物

- 六个状态，每个状态 16 帧，路径为 `src/assets/pet/<state>/00.png` 至 `15.png`。
- 三个静息状态两两之间各有一条 8 帧切换动画，路径为
  `src/assets/pet-transitions/<pair>/00.png` 至 `07.png`；反方向由播放器倒放。
- 偶数编号帧是动作关键帧，奇数编号帧是前后关键帧之间的 50% 过渡，不再作为新的动作
  关键帧单独生成。
- 所有运行帧为 512×512 RGBA PNG；`walking` 朝右，向左由 CSS 水平镜像。
- 统一身份锚点和上一版基础状态表保存在 `artifacts/asset-work/v2/`；本版动作源表、
  静息切换源表、过渡帧预览、最终预览及质量报告保存在 `artifacts/asset-work/v3/`。
- 使用内置图像生成工具，以四张原始参考图建立唯一身份锚点；六个状态均引用该锚点。
- `scripts/process_animation_assets.py` 保持源格比例进行切帧、抠绿、统一脚底基线和视觉
  中心，并以坐姿首帧为基准统一毛色。walking、petting 和 hissing 使用严格限定的 50%
  过渡姿势；其余小幅变化使用双向稠密光流计算 50% 过渡。处理时只保留每格最大的连通
  主体，避免相邻格越界碎片。

## 静息状态切换

| 单向源序列 | 动作内容 | 反向使用 |
|---|---|---|
| `sitting-walking` | 正坐、转身、起立、进入右向站立步态 | 走姿收步、转身坐下 |
| `sitting-sleeping` | 正坐、下伏、收腿、卷尾、闭眼 | 睁眼、展开身体、重新坐起 |
| `walking-sleeping` | 减速、屈腿、伏地、卷尾入睡 | 展开身体、起立进入步态 |

每条源序列恰好 8 帧，首尾替换为对应运行状态的精确端点。处理中按首尾主体面积线性校准
中间帧，避免转身时突然缩放，同时继续锁定统一基线和视觉中心。

## 各状态参考和补全

| 状态 | 实际参考图 | 参考作用 | 补全动作 |
|---|---|---|---|
| `sitting` | 身份锚点、全身、平静 | 固定身体、脸型、毛色、折耳 | 仅眨眼与极轻耳动 |
| `walking` | 身份锚点、全身、平静 | 身份、体型和侧视转换依据 | 朝右慢速完整步态，头身基本不浮动 |
| `sleeping` | 身份锚点、全身、平静 | 毛色、头身比例、折耳 | 固定蜷卧，仅极轻呼吸和尾尖变化 |
| `happy` | 身份锚点、平静、微笑 | 固定身体、开心张嘴表情 | 嘴部逐渐张开、满足眯眼、恢复 |
| `petting` | 身份锚点、平静、微笑 | 固定下身、放松表情、近距离透视 | 头部快速前伸放大、闭眼停顿、收回 |
| `hissing` | 身份锚点、平静、哈气 | 固定下身、飞机耳、牙齿与口腔 | 头部快速前扑张嘴、峰值停顿、闭嘴收回 |

## 一致性与质量检查

- 六套图共享同一身份锚点，保持圆头、淡橘短毛、折耳、深色圆眼和一致的头身关系。
- 1536×1024 接触表的每格为 384×512；处理时居中补边到 512×512，没有横向拉伸。
- 所有帧统一到 `y=487` 承重点和 `x=256` 视觉中心。质量报告显示基线漂移为 0–1 px，
  视觉中心漂移为 1–2 px。
- 以坐姿首帧毛色为统计基准，六个状态及三组静息切换的毛色中值距离均不超过 2.5。
- `petting` 峰值头部宽度相对首帧增加约 33%，`hissing` 增加约 35%，形成明确的近大远小。
- `petting` 和 `hissing` 不再等时播放：约 0.3 秒到达动作峰值，峰值连续停留数帧后恢复。
- 透明角已人工查看；主体轮廓可辨，保留轻微绿缘/旧抠图 halo，符合“包浆”方向。
- `hissing` 峰值帧已人工检查，表达为哈气而非普通打哈欠。
- 最终 4×4 顺序预览已逐状态人工检查，无半透明双腿、双眼或交叉淡化残影。

## 生成提示词摘要

共同约束：四张原始参考图与唯一身份锚点、真实旧视频截帧质感、同一只淡橘圆头猫、
4×2 等分接触表、纯 `#00ff00` 背景、无阴影/文字/道具/额外肢体、固定比例与基线。
静息切换提示词逐帧描述转身、起立、伏地和卷尾过程；petting/hissing 明确要求身体固定、
头部向镜头前伸并放大 20% 左右。过渡表只生成相邻关键帧的 50% 时间位置，不新增峰值。

## 仍需实机确认

- 半透明毛发边缘在不同桌面壁纸上的绿溢色可接受程度；
- Retina 与 Windows 150%/200% 缩放下的轮廓和包浆强度；
- 三组静息切换正放/倒放的主观连续性；
- petting/hissing 非均匀逐帧节奏和头部前伸纵深在 Windows 上的主观效果。
