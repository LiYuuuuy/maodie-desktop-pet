# 动画素材生成报告

## 产物

- 坐姿、睡觉和开心各 32 帧，走路 64 帧，抚摸 33 帧，哈气 31 帧，路径为
  `src/assets/pet/<state>/`。
- 三个静息状态两两之间各有一条 8 帧切换动画，路径为
  `src/assets/pet-transitions/<pair>/00.png` 至 `07.png`；反方向由播放器倒放。
- 复杂动作在相邻关键帧间按区间插入 0、1 或 3 张 50% 递归中间帧；所有帧固定间隔播放。
- 所有运行帧为 512×512 RGBA PNG；`walking` 朝右，向左由 CSS 水平镜像。
- 统一身份锚点和上一版基础状态表保存在 `artifacts/asset-work/v2/`；本版动作源表、
  静息切换源表保存在 `artifacts/asset-work/v3/`；本版动作源表、递归中间表、最终预览及
  首轮质量报告保存在 `artifacts/asset-work/v4/`；v0.1.7 重构的走路关键帧、
  不可变的已验收转场源和上一轮质量报告保存在 `artifacts/asset-work/v6/`；v0.1.8 的
  walking 结构稿、永久分层部件、预览和专项 QC 保存在 `work/walking/` 与
  `outputs/walking/`。
- 使用内置图像生成工具，以四张原始参考图建立唯一身份锚点；六个状态均引用该锚点。
- `scripts/process_animation_assets.py` 保持源格比例进行切帧、抠绿、统一脚底基线和视觉
  中心，并以坐姿首帧为基准统一毛色。walking、petting 和 hissing 使用严格限定的 50%
  过渡姿势；其余小幅变化使用双向稠密光流计算 50% 过渡。处理时只保留每格最大的连通
  主体，避免相邻格越界碎片。v0.1.8 起 walking 不再进入整图光流管线，而由
  `scripts/build_walking_animation.py` 复用同一个 body、LF、RF、LH、RH 五层部件和连续
  关节轨迹直接渲染 64 帧；抚摸与哈气仍按动作快慢选择不同插入数量。

## 静息状态切换

| 单向源序列 | 动作内容 | 反向使用 |
|---|---|---|
| `sitting-walking` | 正坐、转身、起立、进入右向站立步态 | 走姿收步、转身坐下 |
| `sitting-sleeping` | 正坐、下伏、收腿、卷尾、闭眼 | 睁眼、展开身体、重新坐起 |
| `walking-sleeping` | 减速、屈腿、伏地、卷尾入睡 | 展开身体、起立进入步态 |

每条序列直接采用 v0.1.5 已验收的 8 帧动作，只把首尾替换为当前运行状态的精确端点。
这些源帧固定保存在 `artifacts/asset-work/v6/approved-idle-transition-frames/`，与
`src/assets/pet-transitions/` 输出目录完全分离。脚本禁止把输出目录当作下一轮输入，
因此重复运行不会截断序列或叠加插值。

## 一致性与质量检查

- 六套图共享同一身份锚点，保持圆头、淡橘短毛、折耳、深色圆眼和一致的头身关系。
- 1536×1024 接触表的每格为 384×512；处理时居中补边到 512×512，没有横向拉伸。
- 所有帧统一到 `y=487` 承重点和 `x=256` 视觉中心。三种静息状态及三组转场的基线
  漂移均为 0 px，视觉中心漂移为 0.5–1 px。
- 以坐姿首帧毛色为统计基准，六个状态及三组静息切换的毛色中值距离均不超过 1.8。
- `petting` 和 `hissing` 的首尾帧与坐姿首帧逐字节一致；中间动作分别按 1.054 和
  1.190 的统一比例校准，修复互动触发时的整体尺寸跳变。
- `petting` 峰值头部宽度相对首帧增加约 4.0%，`hissing` 约 1.8%，保持原始脸型。
- 坐姿前 16 帧构成无眨眼循环，每轮仅有 25% 概率进入后 16 帧眨眼段。
- 走路保持 64 帧和固定 24 FPS，完整步态约 2.67 秒。LF、RF、LH、RH 拥有永久身份和
  0/4/6/2 的独立相位偏移；主体水平中心全程为 255.5 px，脚底基线全程为 487 px。
  最大相邻变化为中位数的 2.686 倍，循环尾到首仅为中位数的 0.345 倍。
- 透明角已人工查看；主体轮廓可辨，保留轻微绿缘/旧抠图 halo，符合“包浆”方向。
- `hissing` 峰值帧已人工检查，表达为哈气而非普通打哈欠。
- 最终顺序预览已逐状态人工检查，并对走路相邻帧跳变增加自动化上限。

## 生成提示词摘要

共同约束：四张原始参考图与唯一身份锚点、真实旧视频截帧质感、同一只淡橘圆头猫、
4×2 等分接触表、纯 `#00ff00` 背景、无阴影/文字/道具/额外肢体、固定比例与基线。
静息切换提示词逐帧描述转身、起立、伏地和卷尾过程；petting/hissing 明确要求身体固定、
头部仅作轻微抬起或颈部前移，外轮廓限制在中性姿势约 5% 内。过渡表生成相邻关键帧的
50% 时间位置。v0.1.8 的 walking 先用彩色 LF/RF/LH/RH 结构稿锁定八相位，再使用内置
图像生成生成同一只猫的无腿 torso 与四条独立腿部件。正式 64 帧不再调用生成模型补帧，
而由连续骨骼相位直接合成；全部帧统一使用固定部件、中心和脚底基线。
